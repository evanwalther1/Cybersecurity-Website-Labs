## What you need (for Gaby)

Node.js version 20.19 or newer (22 or newer recommended).
Download it from https://nodejs.org (the LTS build). npm is included.

Check what you have:

    node -v

## Running it

1. Clone the repo and go into it:

   git clone https://github.com/evanwalther1/Cybersecurity-Website-Labs.git
   cd Cybersecurity-Website-Labs

2. Install node's dependencies if you haven't already

   npm install

3. Start the site:

   npm run dev

4. Open http://localhost:5173 in a browser.

To stop the server, press Ctrl+C in the terminal.
